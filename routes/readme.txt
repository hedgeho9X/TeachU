EduSpark Routes Directory 说明

文件夹作用:

routes 文件夹负责定义 EduSpark 项目的所有 API 路由。它将 HTTP 请求映射到相应的 controller 处理函数，是应用程序的入口点。该层通常包含路由分组、中间件应用（如 JWT 认证）以及具体的路由规则定义。

各主要路由文件描述:

1.  routes.go:
    作用: 初始化 Gin 引擎，设置全局中间件，并聚合注册所有其他模块的路由。定义了根路径 ("/") 的欢迎信息。

2.  auth_routes.go:
    作用: 定义用户认证相关的路由，包括用户注册、登录、邮箱验证码发送与验证、忘记密码、重置密码等。部分接口需要 JWT 认证。

3.  teaching_routes.go:
    作用: 定义教学管理相关的路由，主要包括班级管理（创建、列表、删除）和学生管理（列表、批量导入、删除）。所有接口需要 JWT 认证。

4.  exam_routes.go:
    作用: 定义考试与成绩相关的路由，包括创建考试、删除考试、获取考试列表，以及上传成绩、获取成绩列表。所有接口需要 JWT 认证。

5.  problems_routes.go:
    作用: 定义题目管理相关的路由，例如创建题目。所有接口需要 JWT 认证。

6.  analysis_route.go:
    作用: 定义学情分析相关的路由，包括班级整体分析、单个学生分析（含 AI 分析）、获取排名等。所有接口需要 JWT 认证。

7.  resource_routes.go:
    作用: 定义教学资源相关的路由，提供资源搜索和获取特定资源对象的功能。

8.  ai_routes.go:
    作用: 定义与 AI 功能集成的路由，包括 AI 聊天、PPT 自动生成（创建、进度查询、模板列表）、图片生成、基于 RAG 的智能推荐（学生个性化推荐、教学计划推荐、通用 RAG）等。大部分接口需要 JWT 认证。
