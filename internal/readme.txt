EduSpark Internal Directory说明

文件夹作用:

internal 文件夹用于存放 Go 项目的核心业务逻辑代码，这些代码不希望被项目外部直接导入和使用，保证了项目的封装性。它包含了 TeachU 应用的主要后端逻辑。

各主要子文件夹及文件描述:

1.  config:
    作用: 存放项目的配置信息。

2.  controllers:
    作用: 处理 HTTP 请求，作为 MVC 架构中的控制层。它们接收用户输入，调用相应的服务处理业务逻辑，并返回响应。

3.  middlewares:
    作用: 存放中间件。中间件用于在请求处理流程中执行通用任务，如身份验证、日志记录等。
   
4.  models:
    作用: 定义数据模型 （Go 结构体），对应数据库表结构或 API 的数据格式。
    
5.  services:
    作用: 包含应用的业务逻辑。被 Controller 调用，负责处理具体业务、操作数据库或调用其他服务。
