# 功能介绍

欢迎使用 EduSpark！本教程将引导您快速了解 EduSpark 的核心功能，体验 AI 如何赋能高效备课。

EduSpark 旨在解决教师备课中的痛点，提供一个集 **AI 教案生成**、**PPT/图片自动化设计**、**个性化资源推荐** 和 **学情分析** 于一体的智能备课系统。

主要功能包括：

*   **智能教案与 PPT / 图片生成**：利用多模态 AI 技术，快速生成教学方案和演示文稿，支持文本、图像等多种内容形式。
*   **精准资源推荐 (RAG)**：基于庞大的教育知识库和课程标准，结合 RAG 技术，为您精准匹配和推荐教学素材。
*   **学情驱动分析**：通过分析学生数据，从班级到个人，识别知识薄弱点，提供个性化的教学策略建议和学习资源。

让我们开始探索 EduSpark 如何简化您的备课流程，提升教学效率！
