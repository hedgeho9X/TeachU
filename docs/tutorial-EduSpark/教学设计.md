# 教学设计

:::tip 如何生成教案
在描述框中输入教案主题以及具体要求，例如教学目标、学生背景、作业设计等。AI将为您生成初步的教学设计方案。
:::

*   **编辑与修改**
    :::info
    根据生成的内容，您可以在右侧编辑栏上方选择工具，对需要修改的部分进行调整。左侧将实时展示修改后的教案内容。
    :::
*   **格式选择与复制**
    :::info
    您可以根据设备需求，在左侧栏目上方选择合适的展示格式。通过快捷键可以直接将内容复制到其他应用中。
    :::
*   **导出**
    :::info
    获取到满意的教学方案后，可以点击右侧栏上方最后一个按钮，将教学内容导出为所需的格式（如 Word、PDF 等）。
    :::

# 生成教学PPT

:::tip 如何生成PPT
在描述框中输入教学主题，可以添加重点页面需求、课堂互动设计等具体要求。
:::

:::info 下载与修改
生成PPT后，点击图片即可下载PPT文件。教师可以根据生成的内容，在本地对PPT进行进一步修改和完善。
:::

# 生成教学图片

:::tip 如何生成图片
描述出图片需求，例如主体对象、场景设定、动作等，并选择所需的图片比例。可以通过拖动权重数值来调整生成结果，以获取更适用的图片。
:::

:::info 图片与说明
AI会同时生成图片以及相应的图片说明，供教师选择和参考。
:::
